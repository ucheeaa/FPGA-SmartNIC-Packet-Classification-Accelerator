# FPGA-SmartNIC-Packet-Classification-Accelerator
FPGA-based SmartNIC packet classification accelerator implemented in Verilog, featuring both a high-throughput architecture design and an area-optimized design. Evaluations for timing, power, and FPGA resource utilizations were performed.
